# 心镜 · 中文心理测试平台

一个面向中文用户的心理测评网站：47 项经典与专业量表，在线作答、即时评分、结果可视化与综合报告。

**在线体验：<https://psych-test-web.pages.dev/>**

## 主要功能

- 47 项测评：WAIS-5 智力量表、MBTI、Goleman EQ、大五人格 OCEAN、Holland RIASEC，以及 PHQ-9、GAD-7、PSS、PSQI、DASS-21、PCL-5、ISI、AUDIT 等专业量表
- 完整流程：选择量表 → 作答 → 自动评分 → 维度雷达图与解读 → 历史记录
- 综合报告：跨量表整合分析，给出优先改善方向与可执行建议
- 账号体系：注册 / 登录、个人档案、测评历史
